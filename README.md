# game

Хоррор-антология из трёх мини-игр про школьные предметы, объединённых сюжетом вокруг зачётки и таинственного «пропавшего ученика». Игрок проходит уроки по математике, программированию и экономике, зарабатывает оценки — а от их итогового среднего балла зависит, какую концовку он получит.

Проект сделан на **Unity 6 (6000.4.4f1)** с Universal Render Pipeline.

## Концепция

Игра начинается в **классной комнате (Hub)**, где на столе лежит зачётка. Через неё игрок выбирает один из трёх предметов и попадает в отдельную мини-игру со своей механикой и жанром. После победы или поражения оценка по предмету меняется, и игра возвращает в хаб.

Когда игрок закрывает зачётку насовсем, подсчитывается средний балл по трём предметам:

- **средний балл слишком высокий (≥ 5.0) или слишком низкий (≤ 3.0)** → плохая концовка («пропавший ученик»);
- **средний балл где-то посередине** → хорошая концовка.

Логика перехода между сценами, хранение оценок и подсчёт концовки реализованы в `LevelBridgeManager` (синглтон, переживающий смену сцен) и `EndManager`.

## Предметы и мини-игры

| Предмет | Сцена | Жанр | Что нужно делать |
|---|---|---|---|
| **Математика** (`Assets/Subjects/MathAnalysis`) | `MathAnalysisGameScene` | Стелс/выживание на уроке | Не заснуть за партой (`SleepMechanicController`), собрать нужное количество записок (`NotesSpawner`/`NoteInteraction`), не шуметь (`SoundNoiseController`) и не терять зрительный контакт с учителем (`EyeContactController`). Сложность (Grade3–5) зависит от текущей оценки: сильнее трясётся камера, темнее виньетка, быстрее «слипаются глаза» |
| **Программирование** (`Assets/Subjects/Programming`) | `ProgrammingScene` | Лабиринт с выживанием | Игрок перемещается по процедурно генерируемому лабиринту (`MazeGenerator`), уклоняется от ловушек (`Trap`, `MarkovTrap2`) и чинит терминалы, отвечая на вопросы по программированию (`Terminal`, `TerminalData`). Нужно починить все терминалы, чтобы снять «файрвол»-барьер и выйти. Сложность и урон от ловушек масштабируются оценкой (Easy/Medium/Hard) |
| **Экономика** (`Assets/Subjects/Economic`) | `EconimicGameScene` | Аркада на время | Топ-даун сбор монет/предметов на ограниченное время с противниками (`EnemyAI`) и подсчётом очков (`ScoreManager`). Чтобы «сдать» урок, нужно занять 1-е место в рейтинге к концу таймера |

Каждая мини-игра завершается вызовом `LevelBridgeManager.finishLevel(bool isWin)`, который повышает оценку по предмету при победе и возвращает игрока в хаб.

## Технологии

- **Unity 6000.4.4f1**, Universal Render Pipeline (URP) 17.4
- **Input System** — управление
- **Cinemachine** — камера
- **AI Navigation (NavMesh)** — враги в экономической мини-игре
- **TextMesh Pro** — UI/текст
- **Timeline**, **Visual Scripting** — вспомогательные модули
- Язык скриптов — C#

## Структура проекта

```
Assets/
├── Scenes/            # HubScene — классная комната с зачёткой
├── Scripts/           # Общая логика: авторизация, зачётка, переходы, LevelBridgeManager
├── Subjects/
│   ├── MathAnalysis/  # Урок математики (сцена, скрипты, спрайты, звук)
│   ├── Programming/   # Лабиринт с терминалами
│   └── Economic/       # Аркада на сбор предметов
├── Shared/            # Общие материалы и текстуры (парта, доска, зачётка и т.д.)
└── Core/               # Прочая общая логика
```

## Как запустить

1. Установите [Unity Hub](https://unity.com/download) и Unity версии **6000.4.4f1** (или новее из ветки Unity 6) через Hub.
2. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/kkentlisa/game.git
   ```
3. Откройте папку проекта через Unity Hub → Open → выберите склонированную папку.
4. В окне `Project` откройте `Assets/Scenes/HubScene.unity` и нажмите **Play**.
